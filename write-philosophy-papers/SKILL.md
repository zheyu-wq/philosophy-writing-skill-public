# 哲学论文写作

以“清楚、简洁、准确地呈现可评估的论证”为首要目标。不要以辞藻、术语密度、篇幅或权威声望而代替推理。

## 1. 明确任务

先判断任务类型：新写论文、拟定提纲、重构论证、扩写片段、修改草稿、评审论文或阅读文献。确认以下约束；只在缺失信息会改变交付结果时提问：

- 题目或哲学问题、课程层级、目标读者；
- 字数或页数、语言、引文格式、提交要求；
- 必用文本、允许使用的资料、用户已有立场与草稿。

修改草稿时保留作者原意；若要改变中心论点，明确说明理由。不要虚构文本、页码、引语、文献或研究结论。

## 2. 把主题变成论点

把名词短语式的宽泛主题改写为可判定真假的陈述句。一个合格论点应当：

1. 明确表态，而非只宣布讨论某问题；
2. 范围足够窄，能在规定篇幅内得到辩护；
3. 强度适当，不主张超出前提支持范围的结论；
4. 使用可控且一致的术语；
5. 能回应“为什么值得争论”。

例如，把“自由意志问题”收窄为“某些受因果决定的行为仍可使行为者承担道德责任”。不要未经用户确认就把示例论点当成最终立场。

## 3. 重构并检验论证

先写论证地图，再写正文：

```text
主结论 C：
前提 P1：
前提 P2：
隐含前提 P3（如有）：
子论证：支持哪个前提？
最强反对意见 O1：攻击哪个前提或推理步骤？
回应 R1：反驳、限定、修正，还是承认失败？
```

分别检查：

- **推理**：前提为真时，结论是否必然或合理地成立？
- **前提**：每个前提是否有证据、直觉、例子、文本或子论证支持？
- **可信度**：目标读者能否识别并接受这些理由，而非仅作者自己接受？
- **举证责任**：谁作出了断言？有争议的前提是否被偷偷当作显然事实？
- **结论强度**：量词、模态词和范围是否超过论证能力？

论证分析、分析策略和反对意见处理详见 [references/argumentation.md](references/argumentation.md)。需要阅读或解释哲学文本时，先读 [references/reading-and-sources.md](references/reading-and-sources.md)。

## 4. 设计论文结构

至少包含以下功能，而不是机械套用固定标题：

1. **引言**：界定问题，交代必要背景与争议，尽早陈述论点，说明重要性、必要假设和论述路线。
2. **提出主论证**：列出前提与结论，解释术语，展示推理关系。
3. **支持前提**：逐一提供证据或子论证；把篇幅集中于最有争议、最承重的前提。
4. **反对与回应**：公正呈现最强反对意见，指出它攻击的环节，再回应；必要时限定或修订原论点。
5. **结论**：准确说明已经证明到什么范围，或解释其意义；不要突然引入全新论证。

允许嵌套子论证，并用路标句说明当前处于“提出论证—反对—回应—修正”的哪一步。顺序由内容决定，不为覆盖模板而添加无关部分。完整结构、起草方法和模板见 [references/drafting-and-revision.md](references/drafting-and-revision.md) 与 [assets/paper-template.md](assets/paper-template.md)。

## 5. 选择起草方法

根据思路成熟度选择，也可组合使用：

- **大纲法**：已知道论点与主要推理时，先安排各部分功能。
- **逐层细化法**：已有中心句但论证未展开时，从“论点，因为……”开始，逐轮补充定义、理由、背景、反对与回应。引言和结论可以后写。
- **概念笔记法**：思路零散或写作受阻时，不加评判地写下词语、例子、疑问和可能立场，再分类、排序、取舍。

不要把自由笔记直接当作成稿。除非任务是解释指定文本，先形成自己的问题意识和初步论证，再针对论证缺口研究二手文献；发现更好或相反观点时，引用、吸收或重构原论证，不掩饰其来源。

## 6. 写作时保持论证可见

- 每段承担一个可说明的功能，主题句尽量直接表达该功能。
- 每句应推进解释、证据、推理、反对或回应；删除只换词重复的句子。
- 专业术语、新造词和有歧义的日常词必须先用更普通的语言解释。
- 优先使用清楚的主语、主动动词和直接句式；明确代词指向。
- 区分“我认为”“我将论证”与个人感受、轶事；后者不能代替公共理由。
- 用“然而”“因此”“这一回应并未……”等标示真实逻辑关系，不用连接词掩盖跳跃。
- 不用侮辱性评价代替批评；说明观点究竟因何不可信。
- 直接引用只用于措辞本身重要、需准确呈现对方立场或原文更清楚时；其余情况优先准确转述并注明出处。

## 7. 分轮修订

不要边写初稿边反复做表面润色。按以下顺序修订：

1. **结构轮**：做反向大纲；检查每段对主论点的贡献、顺序与嵌套关系。
2. **论证轮**：检查有效性、前提支持、隐含假设、量词与模态、反例及最强反对意见。
3. **内容轮**：检查文本解释是否准确，举证责任是否履行，权威是否被误用，结论是否过强。
4. **形式轮**：检查连贯、清晰、简洁、严谨；消除歧义、模糊、离题和重复。
5. **语言与引文轮**：最后处理语法、句式和格式；逐项核对引语、页码、注释和参考文献。

详细检查表见 [references/drafting-and-revision.md](references/drafting-and-revision.md)。

## 8. 按请求交付

- **拟提纲**：交付收窄后的题目、中心论点、论证地图、分段提纲、最强反对意见与待核资料。
- **写全文**：交付标题、完整正文与真实参考文献；遵守字数和格式，不用提纲冒充正文。
- **改草稿**：先列关键诊断，再给出修订稿；重大改动说明理由，避免只改辞藻。
- **评审**：按“问题位置—问题类型—为何影响论证—如何修正”输出，优先处理致命问题。
- **重构论证**：区分文本明言与重构者补充的前提，不把补充内容冒充原作者观点。

交付前检查：中心论点是否仍一致；每个关键断言是否有支持；反对意见是否被公正呈现；所有引文是否可核验；结论是否超出已证明范围。
