## 一、论文结构

### 1. 简易结构

```text
I. 陈述待证明的命题。
II. 为该命题提供论证。
III. 解释前提如何支持结论。
IV. 为前提的真实性或可接受性辩护，并处理反对意见。
V. 说明已经证明的内容或其意义。
```

### 2. 展开结构

**引言**

- 从标题和首句迅速限定讨论范围。
- 只交代理解争议所必需的历史、文本和研究背景。
- 尽早写出中心论点，并澄清其含义。
- 说明问题重要性、无条件采用的假设和必要路线。
- 不用空泛赞美、漫长哲学史或宏大套话拖延入题。

**正文**

- 尽早展示主论证的整体结构。
- 定义技术词，消除与推理相关的歧义。
- 解释不明显推论所依赖的概念关系或逻辑规则。
- 用文本证据、例子、直觉、经验事实或子论证支持前提。
- 提出并回应最强反对意见。
- 将子论证嵌入其支持的前提附近，明确标识论证层级。

**结论**

- 准确总结论点及其已获支持的范围。
- 可解释理论意义或进一步后果。
- 不用新证据、新主张或过度宏大宣言取代收尾。

结构是功能清单而非僵化顺序。内容需要时，可先呈现反对意见再提出自己的论证，或在引言中嵌入对某哲学家论证的重构。

## 二、三种起草方法

### 1. 大纲法

适合论证已较清楚时。每节先写功能，再写要证明的命题。写完后能从成稿反向整理出合理大纲，说明结构至少可被理解；若做不到，先修结构而非润色。

### 2. 逐层细化法

适合已有中心句时：

1. 写一句中心论点。
2. 扩为“论点，因为前提 A 与前提 B”。
3. 补充必要定义和概念区分。
4. 为推理跳跃添加中间步骤。
5. 为争议前提添加证据或子论证。
6. 加入反对与回应。
7. 根据最终论证重写引言和结论。

若发现原论点错误或过强，不要掩盖；将其改为待反驳立场、限定后的立场或新的研究起点。

### 3. 概念笔记法

适合思路模糊时。把每个想法、疑问、例子、可能反驳分别记录，不评判、不排序。积累后按“定义—主论证—前提支持—反对—回应—结论”分类，删除不能服务主论点的材料。

## 三、句段与修辞

- 每段像一个微型论证：有中心、有展开、有与上下文的逻辑连接。
- 把段落主旨放在主句中，除非有明确理由将其置于从句。
- 一句不要塞入多个尚未解释的复杂思想；按推理顺序分句。
- 删除只重复前句、没有推进论证的句子；但保留为澄清复杂思想所必需的重述。
- 重排句子，使主从关系与思想的主从关系一致。
- 使用平行的表达呈现并列立场，用明确路标呈现论证、反对和回应。
- 优先使用主动、具体、有力的动词；减少抽象名词堆叠、无意义限定词和冗长短语。
- 明确“这”“其”“该观点”等指代对象。
- 确保句子字面意思就是论点，不让主语与谓词形成范畴误置。
- 修辞服务于读者识别论证，不服务于显得深刻。

## 四、五轮修订检查表

### 第一轮：结构

- [ ] 标题是否限定真实主题？
- [ ] 首段是否尽早提出有真值、有限定的中心论点？
- [ ] 每段是否能标注功能？无功能段落是否删除或合并？
- [ ] 反向大纲是否显示合理的推理顺序？
- [ ] 子论证是否靠近它支持的前提？结论是否兑现引言承诺？

### 第二轮：论证

- [ ] 前提、隐含前提、子结论和主结论是否可明确区分？
- [ ] 推理是否有效或达到所宣称的非演绎支持强度？
- [ ] 最承重、最有争议的前提是否得到最多支持？
- [ ] 是否测试了反例、量词、模态和替代解释？
- [ ] 是否提出最强反对意见并真正回应，而非改变话题？

### 第三轮：内容

- [ ] 是否准确转述原作者，而非只挑有利措辞？
- [ ] 是否把重构补充误写成文本明言？
- [ ] 是否以权威声望代替其理由？
- [ ] 是否对断言承担了举证责任，并明示不作证明的假设？
- [ ] 结论是否比前提支持的更强？

### 第四轮：形式

- [ ] 句子、段落和部分之间是否有真实逻辑连续性？
- [ ] 专业词、多义词、模糊词和代词是否清楚？
- [ ] 是否删除离题、重复、空泛开头和不必要限定词？
- [ ] 是否保持概念、术语和论证标准一致？

### 第五轮：语言与引文

- [ ] 主谓搭配、句法、标点和指代是否正确？
- [ ] 直接引语是否逐字核对，转述是否忠实？
- [ ] 引文页码、版本、注释与参考文献是否对应？
- [ ] 是否只列实际使用且可核验的文献？
- [ ] 是否遵守指定字数、语言和引文格式？
